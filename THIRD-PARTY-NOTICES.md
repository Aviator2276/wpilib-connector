## 2. Third-party software inside WPILib and the GUI bundle

WPILib itself bundles third-party software (Dear ImGui, ImPlot, GLFW, fmt,
LLVM support code, JSON for Modern C++, nanopb, mpack, Eigen, stb, the
embedded fonts and others). The complete licence texts, taken from the same
allwpilib checkout the bundle was compiled from, are generated at build time
by `wasm/tools/collect_licenses.py` and shipped next to the bundle as
`wasm/<version>/THIRD-PARTY-NOTICES.txt`, which the daemon serves at
`wasm/<version>/THIRD-PARTY-NOTICES.txt`.

The bundle also links:

- **Emscripten** runtime and system libraries (musl, libc++, compiler-rt):
  MIT License / University of Illinois NCSA Open Source License.
- **emscripten-glfw** (the `contrib.glfw3` port, by pongasoft): Apache
  License 2.0.

## 3. portable-file-dialogs

`wasm/patches/2026/overlay/wpigui/src/main/native/cpp/portable-file-dialogs.cpp`
is a new implementation of the interface declared by
[portable-file-dialogs](https://github.com/samhocevar/portable-file-dialogs)
(Sam Hocevar, WTFPL version 2), whose header WPILib vendors. No code from the
original implementation is used.

The built shell (`web/dist`) bundles React and React DOM (MIT, Meta Platforms),

## 7. Vendor libraries

The test robots under `tests/robots/` reference vendor libraries through
their published `vendordeps` JSON descriptors (CTRE Phoenix 6, REVLib,
Studica, PhotonLib). The libraries are downloaded from the vendors' Maven
repositories at build time under each vendor's own licence; none is
redistributed here.
